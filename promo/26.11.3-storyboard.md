## 录制技巧

1. **每段用环境变量直达页面**，避免录制时找菜单、镜头抖：
   ```bat
   set HIL_START_PAGE=home:dashboard   && start HugeInsaneLauncher.exe   :: 第 2 段
   set HIL_START_PAGE=more:fun         && start HugeInsaneLauncher.exe   :: 第 3 段
   set HIL_START_PAGE=account          && start HugeInsaneLauncher.exe   :: 第 4 段
   set HIL_START_PAGE=more:tools HIL_TOOLS_TAB=seed    :: 第 5 段
   set HIL_START_PAGE=more:tools HIL_TOOLS_TAB=recipes :: 第 6 段
   set HIL_START_PAGE=settings:launcher                 :: 第 7 段
   ```
2. 鼠标移动要**慢而连续**：磁吸、推挤让位、指示框滑动都靠这个体现，快速甩鼠标看不出来。
3. 第 5 段等 HUD 显示「已加载 8/8 块」再开始拖，否则拍到的是半张图。
4. 第 7 段的 ✓ 只在改动后出现，**先改再点**，别让观众等。
5. 第 8 段的 Shift+S 要按住 1.5 秒再松，两次。
6. 录制前把 `config.ini` 的 `Onboarded=1`（第 2–8 段）与 `=0`（第 9 段）分开，避免引导遮住界面。
7. 结尾 Logo 板建议用官网同一套配色（主题绿 `#55C45A`）。
