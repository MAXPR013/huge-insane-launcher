# HIL 26.11.4 更新公告（简版）

**Huge Insane Launcher 26.11.4 已发布**
下载：https://hugeinsane.pages.dev ｜ 3.3 MB，一个 exe，双击即用

**这版加了什么**

- 首页小部件：签到、今天玩什么、服务器动态、新闻、公告，都能拖动缩放
- 找乐子：小部件看板，拖一下就重排（会自己让位）
- 工具页：种子地图（村庄/神殿/沉船/矿洞/要塞/末地要塞/出生点）、合成查询（3×3 + 真实物品图标）
- 账号页重做：列表 + 详情，皮肤正面图
- 导航栏自己排：设置 → 启动器设置 → 导航，拖动排序、× 删掉、＋ 加回，按住 Shift+S 偷看被藏的
- 新手引导改成 7 步，第一次用也不迷糊

**修了这些**

- 新闻以前是写死的假标题，现在直接抓 minecraft.net 的真实文章，点开是原文
- 签到以前写死「连续 6 天」，现在按天真实记录，点日期打卡
- 合并查询里的方块图标改成本地预渲染的 3D 图标，拷到别的电脑也不会变平面
- 种子地图分块缓存 + 分级缩放，放大缩小基本不用等

**已知问题**

- 微软正版登录还没接（需要 Azure 应用 ID），现在支持离线与第三方登录
- 新闻/公告走的是内置抓取，官方站改版可能需要跟一次

反馈直接回帖或提 issue：https://github.com/MAXPR013/huge-insane-launcher
