# HIL 宣传片分镜脚本（v3 · 文字砸脸式）

> **状态：2026-08-28 起暂停，两个月后重启。** 重启时从本文件继续。
> 参照：`参考视频/屏幕录制 2026-08-25 213536.mp4`（BlockHelm Launcher 宣传片，71s，逐 2s 帧分析过）。
> v1/v2（界面为主+字幕轨）已被否，**v3 是定稿方向**：文字为主、界面为辅。

## 核心语法（每一拍都遵守）

- **每一拍 = 一句砸脸的大字 + 一张"证据卡"**（UI 截图缩到 1/3 内，圆角细边轻阴影，作用只是"不信你看"）
- 文字占画面 60-80%，超粗黑体，关键词染主题绿
- 每拍 2-3 秒，硬切踩 BGM 鼓点；文字 0.3s 弹入（1.3→1+淡入），证据卡延迟 0.2s 侧滑入
- 全片只用"弹入、放大、变色"三种动效，无转场花活
- 无底部字幕轨（信息全在大字里）
- 排版三式轮换防单调：字左图右 / 字上图下 / 超大字出血+证据卡贴角
- 杀手锏是对照句："别家分析，H史 修"

## 全局规则

- 1920×1080，全片白色主题（底 #FFF/#FAFAFA，字 #222/#888，点缀只用主题绿）
- **顶栏常驻**：40px 白色亚克力（70% 透明白+背景模糊）黑字 14px
  「详细信息请前往官网 hugeinsane.pages.dev」——每一帧都在，不动画不消失
- 收尾卡不重复写官网（顶栏已带）
